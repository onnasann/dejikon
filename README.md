# まちナビ

「デジタルコンテンツ.pdf」の企画をもとにした React + Leaflet の試作版です。

## 起動

```powershell
npm.cmd install
npm.cmd run dev
```

表示されたローカルURLをブラウザで開いてください。ビルドは `npm.cmd run build`。

## 実装済み

- 店舗名・エリア検索とエリア絞り込み
- OpenStreetMap地図、店舗選択、対応する交換所の表示
- 道路に沿った徒歩経路・距離・所要時間の表示とGoogleマップの徒歩経路リンク
- サンプルATMの表示切り替え
- 現在地表示（位置情報の許可が必要）
- スマートフォン用レイアウト、検索結果なし・地図通信エラーの表示

## データと残りの作業

`src/data.json` の店舗・交換所・ATMはすべて架空です。実際の位置・対応関係・営業時間・入口情報を調査し、確認日・情報源とともに登録してから実用化してください。

緑の線はValhallaの徒歩モード（`costing: pedestrian`）から取得した経路です。APIのGeoJSON座標をLeafletに渡して描画します。距離・所要時間は推定値です。座標が道路外の場合、始点・終点は近くの通行可能な道路に補正されます。サンプル座標のため、実在する店舗入口への案内には利用できません。

通信エラーや経路が見つからない場合は経路線を描画せず、再試行ボタンを表示します。店舗切り替え時は前の通信を中止します。同じ経路は10分間メモリに保存し、連続取得を抑えます。経路APIには選択した店舗と交換所の座標を送り、現在地は送りません。

APIキー不要の [Valhalla / FOSSGIS公開デモサーバー](https://valhalla.github.io/valhalla/start/introduction/#public-demo-server) を使用します。[公式API仕様](https://valhalla.github.io/valhalla/api/route/api-reference/) に従っています。デモサーバーには利用制限があり、継続稼働は保証されません。一般公開時は運営者への連絡・識別ヘッダーなどの利用方針を確認するか、本番用のサービスや自前のValhallaに切り替えてください。接続先は `src/routing.js` に定義しています。

経路取得処理のテストは `node --test src/routing.test.js` で実行できます。

景品画像は未登録です。掲載許可のある写真の収集後、データと表示を追加してください。

地図タイル・経路API・Googleマップ・Webフォントにはインターネット接続が必要です。配信元の利用条件に応じた設定・運用を行ってください。現在地は画面表示のみに使用し、保存しません。
